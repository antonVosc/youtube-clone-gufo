# Тестирование

```bash
docker compose exec api pytest -q # 51 тест
docker compose exec -T api python scripts/smoke.py # сквозной сценарий на живом стенде
npm i jsdom && BASE=http://localhost node scripts/ui_smoke.js # SPA в jsdom против стенда (нужны демо-данные)
```

Тесты используют **отдельную БД** `<имя>_test` (создается автоматически — рабочие и демо-данные не затрагиваются) и фейковое S3 в памяти. Транскодер в большинстве тестов подменн, но `test_transcode_ffmpeg.py` гоняет настоящий ffmpeg (HLS 360p+720p, превью, видео без звука, мусор на входе).

| Файл                       | Инварианты                                                                                                                  |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `test_auth.py`             | регистрация/вход, дубликаты, валидация, argon2, ротация refresh, logout, блокировка                                         |
| `test_access.py`           | **№1, №2**: private/unlisted/hidden/processing во всех выдачах и на `/api/media/auth`; шаринг; разбор путей медиа           |
| `test_upload.py`           | **№5**: init → complete → processing → ready; magic bytes; лимиты; владелец; ошибка транскодера; очистка брошенных загрузок |
| `test_social.py`           | **№3**: идемпотентный лайк; комментарии и права удаления; подписки; плейлисты; поиск и лента                                |
| `test_rbac.py`             | **№4**: роли, модерация, жалобы, права на удаление                                                                          |
| `test_ratelimit.py`        | лимитер и защита логина                                                                                                     |
| `test_frontend_static.py`  | **№6**: запрещенные DOM-API, inline-скрипты                                                                                 |
| `test_transcode_ffmpeg.py` | настоящий ffmpeg                                                                                                            |

`scripts/smoke.py` — то, что `deploy.sh` запускает в конце: **регистрация → загрузка (presigned multipart через Nginx) → транскодинг воркером → просмотр HLS (с проверкой приватности) → лайк → комментарий → лента и поиск**.
